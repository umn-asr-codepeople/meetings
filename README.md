# Code People Meeting Planning

The mostly-nailed-down agendas are in [agendas.md](agendas.md). Ideas for upcoming talks are in [ideas](ideas.md).

### How Do I Propose a Talk?

Make [an issue](https://github.umn.edu/code-people/meetings/issues) describing your talk. We can discuss it there and then add it to the talk list. You do not have to give a talk if you propose it. If there's something that you want to learn about, propose a talk! We'll try to find someone to give that talk.
